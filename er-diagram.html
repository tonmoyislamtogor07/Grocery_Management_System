Sufian Store · MySQL database gms_db · drawn from database.sql (actual schema)
Legend: underlined = primary key (PK)  ·  italic = foreign key (FK)  ·  1 / M = one-to-many cardinality.
Notes (matches the real schema, not the old draft):
1. There is no stock_logs table — stock moves through stock_lot batches only.
2. product stores no stock, cost or expiry — live stock, average cost and earliest expiry are derived from stock_lot via the read-only view v_product_live (views are not shown in the ER).
3. Bill totals, paid and due are derived at read time — purchase/sale store no total_amount, final_amount or cash_received.
4. One purchase line creates exactly one batch (purchase_detail 1 — 1 stock_lot); each sale consumes oldest-expiry batches first (sale_lot keeps the audit + exact COGS).
5. Walk-in sale need no customer record (sale.customer_id is NULL-able).
6. FK actions: purchase.supplier_id RESTRICT · product links / sale lines / payments CASCADE · category & customer references SET NULL · lots SET NULL / RESTRICT.
